∑ 把直觉变成证明

递推式为什么总是回到 1 / 2？

第一位的选择只有三类：立即成功、立即失败，或把问题缩小成同一种问题。

选 1 号座位立即成功贡献 1
选中间座位缩成同类问题贡献 p(2) 到 p(n−1)
选最后座位立即失败贡献 0

点击开始，再逐步把“接力棒”写成数学语言。

第 1 行n · p(n) = 1 + p(2) + p(3) + ··· + p(n−1)
第 2 行(n−1) · p(n−1) = 1 + p(2) + ··· + p(n−2)
相减n · p(n) − (n−1) · p(n−1) = p(n−1)
得到p(n) = p(n−1)
起点p(2) = 1 / 2 → p(n) = 1 / 2

公式里的每一个 p(k)，都代表一次“中间座位继续传递接力棒”。

🧠 两个终点的对称性

为什么答案恒为 1 / 2？

连锁过程最终只会在 1 号座位 与 N 号座位之间结束。

1
第一位选中 1 号座位后面每个人都能坐回自己的座位，最后一位成功。
成功
2
第一位选中 N 号座位最后一位只剩 1 号座位，最后一位失败。
失败
…
第一位选中其他座位座位被占的乘客继续随机选择；直到 1 与 N 两个终点之一被选中。
继续
1 号座位↔N 号座位
两个终点完全对称，因此总概率 = 1 / 2 = 50%
